# Homelab K3s Cluster
This is my personal homelab where i will explore devops and self hosting. I decided on using a k3s cluster based on what is used in the real world and the benefits in scalability and self healing seems very useful to have in the knowledge bank :)
## Cluster status
- control plane: k3s-control
- worker node: k3s-worker
- Infrastructure: traefik, LetsEncrypt, Longhorn, Grafana, Loki,
